# BlogSphere - Professional Blog Platform

BlogSphere is a responsive blog platform developed using HTML, CSS, and JavaScript.

## Features

- User Registration and Login
- Professional Dashboard
- Explore Blogs
- Create and Publish Blogs
- Save Blog Drafts
- My Blogs Management
- User Profile
- Blog Categories
- Search Blogs
- Responsive Design
- Local Storage Support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Responsive Web Design
